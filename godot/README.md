# ملفات لعبة الرعب (Godot)

حط هنا أي ملف تبي يدخل اللعبة، وكلّم Claude يحطه في مشروع horror-godot.

| المجلد | وش تحط فيه |
|---|---|
| `models/` | الموديلات والشخصيات والحركات (glb, gltf, fbx, obj) — من poly.pizza و Mixamo |
| `sounds/` | الأصوات والموسيقى (ogg, wav, mp3) |
| `textures/` | الصور والخامات (png, jpg) |

طريقة الرفع: افتح المجلد في جيتهاب ← Add file ← Upload files ← اسحب الملفات ← Commit changes.
