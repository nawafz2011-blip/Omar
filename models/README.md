# مجلد الأشياء

حط هنا كل الملفات اللي تحملها من برا:

- ملفات **GLB** من poly.pizza أو quaternius.com
- ملفات **FBX** من mixamo.com

سمّ الملف اسم واضح بالإنجليزي، مثل: `zombie.fbx` أو `mario.glb` أو `house-big.glb`.

## مهم
بعد ما ترفع ملف جديد، قل لـ Claude يضيفه في `index.json` عشان يطلع في الورشة.
